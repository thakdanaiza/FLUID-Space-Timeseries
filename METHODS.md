# FLUID-Space Time-Series Research Methods Reference

This file describes the time-series analysis implemented in this FLUID-Space variant. Confirm the software version, frame range, profile, and study-specific acquisition details before reusing the text.

## Method summary

FLUID-Space samples a user-defined frame range from a 1090 x 340 pixel experiment video. The range is defined by Start frame, End frame, and Frame step. The operator selects one or more result channels from CH1-1, CH1-2, CH2-1, and CH2-2; only selected channels are processed and exported.

For channel `c`, the fixed analysis mask is:

```text
M_final,c = (M_CAD,c ∩ M_ROI,c ∩ M_interest-zone,c) − M_calibration
```

The registered CAD layout is authoritative. Channel ROIs and channel-specific Interest Zones can remove CAD pixels but cannot add pixels outside the CAD interior. Enclosed CAD holes remain outside the mask.

Bubble annotations remain available in the profile editor for compatibility with the established UI, but they are not applied to the time-series masks or results.

## Frame sampling

Sampled frame indices are generated as:

```text
Start, Start + Step, Start + 2×Step, ... ≤ End
```

The End frame is included only when it lies on this uniform interval. The graph reports elapsed time relative to the Start frame. The CSV records both elapsed time and absolute video time using the video frame rate.

## Color calibration

CH1 and CH2 use separate calibration regions. For every sampled frame, each calibration region is divided into four interior patches. Low-saturation patches below 0.2 are omitted, and each remaining hue is matched to the nearest circular reference hue among 0, 1/3, and 2/3.

Per-frame hue shifts are combined using a circular mean for CAL-CH1 and CAL-CH2 separately. The resulting group-specific shift is fixed for the full frame range, ensuring that all time points share the same calibration basis. A run stops with the affected frame number if calibration cannot be calculated for any sampled frame.

## Phase-index calculation

Each sampled frame is converted from RGB to HSV. Hue is corrected by the averaged group-specific calibration shift. Circular hue distance is calculated to the fixed reference centers:

```text
h_oil   = 0.110
h_water = 0.465
```

For every valid pixel:

```text
d_oil   = circular_distance(h, h_oil)
d_water = circular_distance(h, h_water)
P       = 1 + d_water / (d_oil + d_water + epsilon)
```

The phase index ranges from approximately 1 to 2, where 1 represents the water reference and 2 represents the oil reference. The time-series value is the arithmetic mean of all valid phase-index pixels in one channel at one sampled frame. Its standard deviation and valid-pixel count are retained in the CSV.

## Outputs and provenance

Each run is stored in `profiles/<profile-name>/runs/run_xxx/` and contains only:

- `graphs/phase_time_series.png`: one subplot per selected result channel, with a shaded mean ± 1 SD band
- `time_series.csv`: frame-level values in long format
- `summary.json`: frame range, sampled frames, video and geometry hashes, calibration values, and channel summaries

No phase maps, mask images, QC images, PDF files, or NumPy arrays are generated by this workflow. Retain the profile, source video, CSV, summary, and graph with the study record.

- Blinding, randomization, exclusions, and data/code availability

## Important interpretation limit

The phase index is a calibrated hue-distance index, not automatically a volumetric phase fraction. Do not describe it as oil fraction, water saturation, concentration, or holdup unless that relationship has been independently validated for the optical setup, dyes, illumination, camera, channel material, and fluid system.
